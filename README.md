# Name Fame — Official Site

Marketing site for the **Name Fame** illustrated keepsake book series.
One name, one book: history, symbols, numerology, and the ten legends who carried it.

**10 Legends · 1 Name · Your Story**

## Stack

Static site — plain HTML / CSS / vanilla JS, no build step.

- `index.html` — single page (hero, concept, inside the book, symbols, numerology + interactive calculator, collection, your story)
- `styles.css` — gold & navy theme matching the books (`#C9A84C` / `#1B3A6B` / cream `#F5F0E8`)
- `script.js` — Pythagorean numerology calculator, mobile nav
- `images/` — logo extracted from the book back cover, sample cover, symbol artwork
